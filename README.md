# gmtk-2025
What would have been my submission to the 2025 GMTK Game Jam, if I was able to finish it in time. Regardless, the project is in a finished state and works as a cute proof of concept.
## Installation
Navigate to powershell and run the following:
```bash
git clone https://github.com/gavgrub/gmtk-2025.git
cd gmtk-2025
```
## Running
Navigate to powershell and run the following:
```bash
python main.py
```
